A complete design language and component library for building consistent, high-performance digital experiences. Monicore combines editorial authority with technical precision, offering a "Studio Minimalist" aesthetic that is fully customizable in real-time.

## 🔗 Live Site
**View the Production Style Guide:** [https://design-system-rose-eight.vercel.app/](https://design-system-rose-eight.vercel.app/)

## ✨ Key Features

- **Dynamic Token Engine:** Real-time customization of colors, typography, and border radii via the Studio Sidebar.
- **Auto-Harmony Intelligence:** Automatically generates secondary and tertiary color palettes based on primary hue shifts using `chroma-js`.
- **Advanced Typography:** Access to 36+ hand-picked Google Fonts (18 Display, 18 Sans-Serif) curated for modern interfaces.
- **Production Exports:** One-click export of design tokens to CSS, Markdown specifications, or Tailwind CSS configuration snippets.
- **Theme Stability:** Fully reactive Light and Dark modes with fixed anchors to ensure visual consistency.
- **Visual Capture:** Integrated screenshot utility to capture and share design snapshots instantly.

## 🛠 Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS 4.0
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Color Manipulation:** Chroma.js
- **Type:** Google Fonts (Dynamic Loading)

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the results.

## 📁 Project Structure

- `/app`: Next.js App Router pages and global styles.
- `/components/ui`: Atomic component library (Buttons, Inputs, Cards, etc.).
- `/lib`: Design context, token management, and utility functions.
- `/public`: Static assets and icons.
